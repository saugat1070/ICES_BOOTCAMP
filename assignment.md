## [ ] Assignment 0.0.2 - Social Profile Object

Create an object with the following structure:

```json
{
    "fullName": "Saugat Giri",
    "email": "saugatgiri1070@gmail.com",
    "numberOfLike": 100,
    "comments": ["x", "y", "z"],
    "bookmarks": false,
    "friendsName": ["xyz", "abc"]
}
```

### Methods to Implement

- **Like** - Increment `numberOfLike`
- **Profile Edit** - Update `fullName` and `email`
- **Comments** - Add and remove comments
- **Friends** - Add and remove friends
- **Bookmarks** - Toggle bookmark status
